# 22: 单实例运行与崩溃后恢复

**What to build:** 玩家再次打开 app 时唤起原实例, 异常退出后重启不会被残留任务或不完整缓存干扰.

**Blocked by:** 03: 验证最小 macOS application; 05: 取消加载并隔离过期结果; 06: 复用有效缓存并安全重建损坏产物.

**Status:** ready-for-agent

- [ ] 同一用户配置只运行一个拥有任务和缓存写入权的实例, 再次启动唤起原实例.
- [ ] 明确 session/job/helper ownership, 原实例退出或崩溃后的恢复不依赖不可靠的 PID 存在判断.
- [ ] 只回收确认属于旧 session 的 helper 与 staging, 不终止无关进程或删除有效产物.
- [ ] 验证快速重复启动、启动竞态、崩溃后残留 helper 和恢复期间再次启动.
- [ ] 打包后的 app 中复现上述行为, 不只在编辑器或单元测试内通过.
