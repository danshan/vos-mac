# 20: 有界加载音频并回收播放器

**What to build:** 玩家在密集音符和长时间游玩时获得稳定音频, 退出 gameplay 后资源可回收.

**Blocked by:** 04: 打通 bundle v2 到 Gameplay Ready.

**Status:** ready-for-agent

- [ ] 以可复用、有界 player pool 替代逐事件无限创建, 容量与满载行为基于压力输入证据确定.
- [ ] 必要音频资源准备与 Gameplay Ready 一致, 不把未准备可播放资源计为 Ready.
- [ ] 密集和长时间场景验证播放行为、峰值资源以及重复进入/退出后的增长, 不只验证对象数量常量.
- [ ] 播放结束、取消加载和退出 gameplay 正确释放所属资源, 不误回收仍在使用的资源.
- [ ] 限制资源不能静默丢失合同要求的音频; 如压力场景超能力, 按明确上限诊断而非伪造通过.
